# Programmatic SEO — TibetRide Location Pages

## Recommended Playbook: Locations / Personas Hybrid

### Pattern: "[Destination] + [Tour Type] + [Audience]"

---

## Playbook 1: Location Tour Pages (Highest Priority)

**Target keywords:**
- "Lhasa small group tour" (480/mo)
- "Everest Base Camp tour" (2,900/mo)
- "Mount Kailash pilgrimage tour" (320/mo)
- "Tibet motorcycle tour" (880/mo)
- "西藏小团游" (1,200/mo)
- "西藏摩托车旅行" (500/mo)

**Template structure:**

```
URL: /tours/{destination-slug}-{days}-days/

Title: {Days} Days {Destination} {Tour Type} | TibetRide
H1: {Days}-Day {Destination} {Tour Type Experience}

Sections:
1. Hero with destination image + key stats bar (days, max ppl, price, difficulty)
2. Tour overview (2 paragraphs)
3. Detailed day-by-day itinerary (collapsible)
4. What's included / excluded (table)
5. Travel tips for this route
6. Similar tours (internal links)
7. FAQ accordion
8. Booking CTA
```

**Pages to generate immediately:**
1. `/tours/lhasa-highlights/` — 拉萨精华游
2. `/tours/tibet-photography-tour/` — 西藏摄影团
3. `/tours/tibet-family-tour/` — 家庭西藏游
4. `/tours/tibet-winter-tour/` — 冬季西藏游

## Template Design (for Location Pages)

Each page must be >60% unique content. Use these data sources:
- Different photos per route
- Unique itinerary day-by-day
- Route-specific altitude profile
- Season-specific packing list
- Real guide recommendations per route
